# AiBox.DevPortal
Blazor Server
Radzen Components
.NET 9
Feature-based structure
Services folder contains business services
Models folder contains DTOs and domain models
Prefer async methods
Build must succeed before task completion

## Purpose
Local Blazor/Radzen portal for AI-box development.

## Architecture
- Components = UI
- Services = Business logic
- Models = DTOs and persisted objects
- Data = Runtime storage

## Rules
- Prefer small feature slices.
- Generate patch previews before applying.
- Reuse existing services before creating new ones.
- Use Radzen.Blazor components.
- Keep Razor pages thin.
