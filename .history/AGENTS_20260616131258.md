# AiBox.DevPortal

## Project Purpose

AiBox.DevPortal is a local AI-assisted development portal built with Blazor and Radzen.

Its primary goal is to provide a structured environment for planning, generating, reviewing, verifying, and applying software changes using local AI models running on AI-Box infrastructure.

The portal acts as an orchestration layer between developers, local LLMs, project knowledge, project history, and code-generation workflows.

---

## Core Architecture

AiBox.DevPortal follows a service-oriented, feature-driven architecture.

### Workflow

Planner
→ Task Plan
→ Task Slices
→ Patch Preview
→ Verification
→ Apply Changes
→ Project History

All new development should support and extend this workflow.

### Major Systems

#### Local Coder

Provides AI-assisted development capabilities including:

* Planning
* Task decomposition
* Patch generation
* Verification
* Execution history

#### Project Knowledge Index

Maintains searchable knowledge about the repository structure and codebase.

#### Project History Index

Stores completed features, pending work, implementation history, and recommended next slices.

#### Verification Pipeline

Validates generated changes before they are applied to the project.

## Development Rules

### General

* Prefer small, incremental slices.
* Build before considering work complete.
* Maintain nullable reference safety.
* Use dependency injection.
* Use async/await for I/O operations.
* Avoid business logic inside Razor components.

### UI

* Prefer Radzen components.
* Keep pages focused on presentation.
* Move reusable logic into services.

### Services

* Encapsulate business rules in services.
* Avoid duplicating logic.
* Reuse existing services before introducing new ones.

### Models

* Keep models simple and focused.
* Use explicit request/result types for workflows.
